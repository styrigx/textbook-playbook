# 普林斯顿微积分读本

Adrian Banner 著，杨爽 / 赵晓婷 / 高璞译，人民邮电出版社（第2版）。

全书主线：预备知识 → 极限 → 微分 → 微分应用 → 积分 → 积分方法 → 反常积分 → 级数 → 泰勒 → 专题（参数/复数/体积/微分方程）。本书最大特点是讲"怎么想"：每类题先给思考路径再给套路。
