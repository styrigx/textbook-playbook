# 第21章 反常积分：如何解题

上一章是理论，本章是实战手册：拿到一道反常积分，先找破裂点并拆分，再按"函数在 $\infty$、$-\infty$、$0$ 附近长什么样"选判别法；本章把常见函数的渐近表现整理成速查表。

## 21.1 如何开始

### 21.1.1 拆分积分

- 第一步永远是找"问题点"：积分限含 $\pm\infty$，或被积函数在区间内某点无界
- 每个问题点都要拆：$\int_a^\infty$ 在无穷处取极限；内部瑕点 $c$ 拆成 $\int_a^c+\int_c^b$
- 拆出的每一段只含一个问题点，单独判断敛散；一段发散则整体发散（求值题除外）
- 拆分点选在问题点处，不要选在"好点"处拆（拆了也没用）
- 例：$\int_0^\infty\frac{dx}{\sqrt{x}(1+x)}$ 在 0 和 $\infty$ 各有一个问题，拆成 $\int_0^1+\int_1^\infty$

### 21.1.2 如何处理负函数值

- 比较类判别法要求非负；被积函数变号时先取绝对值，用绝对收敛判别法
- 若 $\int|f|$ 收敛，直接得 $\int f$ 收敛，不必再管符号
- 若 $\int|f|$ 发散，$\int f$ 可能条件收敛（如 $\frac{\sin x}{x}$）也可能发散，需另想办法（分部积分、狄利克雷判别法等，本书不展开）
- 拆正负部 $\int f=\int f^+-\int f^-$ 是理论写法，做题一般不用

## 21.2 积分判别法总结

- 直接计算：能积出来就取极限，最可靠
- p 判别法：基准尺，$\int_1^\infty x^{-p}$（$p>1$ 敛）、$\int_0^1 x^{-p}$（$p<1$ 敛）
- 比较判别法：$0\le f\le g$，"小敛则敛，大散则散"，需凑不等式
- 极限比较判别法：算 $\lim f/g$，非零有限则同敛散，最常用
- 绝对收敛判别法：变号函数先取绝对值
- 选用顺序：先看能否直接算 → 抓主项往 $x^{-p}$ 上靠 → 极限比较 → 需要时取绝对值

## 21.3 常见函数在 ∞ 和 -∞ 附近的表现

### 21.3.1 多项式和多项式型函数

- $x\to\infty$ 时抓最高次项：$3x^2+5x+1\sim3x^2$
- 分式抓"分子最高次/分母最高次"：$\frac{x^2+1}{x^4+3x}\sim\frac{1}{x^2}$
- $x\to-\infty$ 时注意符号：奇次项变号，但取绝对值比较时只看次数
- 根式：$\sqrt{x^2+1}\sim|x|$，$x\to\infty$ 时 $\sim x$

### 21.3.2 三角函数

- $\sin x,\cos x$ 有界振荡：$|\sin x|\le1$，取绝对值后可直接放缩
- $\frac{\sin x}{x^p}$：$\left|\frac{\sin x}{x^p}\right|\le\frac{1}{x^p}$，$p>1$ 时绝对收敛
- $\sin(x^2)$ 等振荡更快，但有界性不变，比较时同样处理
- 注意：$\int_1^\infty\sin x\,dx$ 发散（原函数 $-\cos x$ 无极限），有界不代表可积收敛

### 21.3.3 指数

- $e^x$ 的增长快过任何多项式：$\lim_{x\to\infty}\frac{x^n}{e^x}=0$
- $e^{-x}$ 的衰减快过任何多项式倒数：$x$ 充分大时 $e^{-x}\le\frac{1}{x^p}$（对任意 $p$）
- $\int_a^\infty e^{-x}\,dx$ 收敛；$\int_a^\infty e^{x}\,dx$ 发散
- $e^{-x^2}$ 衰减更快，$\int_0^\infty e^{-x^2}\,dx$ 收敛（值 $\frac{\sqrt\pi}{2}$，记住结论即可）

### 21.3.4 对数

- $\ln x$ 增长慢过任何正幂：$\lim_{x\to\infty}\frac{\ln x}{x^p}=0\ (p>0)$
- 比较时 $\ln x$ 可"忽略"：$\frac{\ln x}{x^2}$ 按 $\frac{1}{x^{1.5}}$ 处理得收敛（严格用极限比较：$\frac{\ln x/x^2}{1/x^{1.5}}=\frac{\ln x}{\sqrt{x}}\to0$，且 $\int x^{-1.5}$ 收敛）
- $\int_2^\infty\frac{dx}{x\ln x}$ 发散：换元 $u=\ln x$ 得 $\ln(\ln x)\to\infty$
- $(\ln x)^q$ 同样慢于任何 $x^p$

## 21.4 常见函数在 0 附近的表现

### 21.4.1 多项式和多项式型函数

- $x\to0$ 时抓最低次项：$x^2+3x\sim3x$
- 分式同样：$\frac{x+1}{x^3+2x^2}\sim\frac{1}{2x^2}$（分子 $\to1$，分母 $\sim2x^2$）
- 往 $\int_0 x^{-p}$ 上靠，$p<1$ 收敛

### 21.4.2 三角函数

- $\sin x\sim x$，$\tan x\sim x$（$x\to0$）
- $1-\cos x\sim\frac{x^2}{2}$
- $\frac{\sin x}{x}\to1$，故 $\int_0^1\frac{\sin x}{x}\,dx$ 的被积函数在 0 处是可去间断（补定义后连续），它是正常积分，收敛
- $\sin\frac1x$ 在 0 附近振荡但有界，$\left|\sin\frac1x\right|\le1$

### 21.4.3 指数函数

- $e^x-1\sim x$（$x\to0$）
- $e^{1/x}$ 在 $0^+$ 处爆炸（$\to\infty$），在 $0^-$ 处 $\to0$；左右表现不同，拆开看
- $e^{-1/x^2}$ 在 0 处比任何 $x^n$ 都更快趋于 0

### 21.4.4 对数函数

- $\ln x\to-\infty$（$x\to0^+$），但慢于任何 $x^{-p}$：$\lim_{x\to0^+}x^p\ln x=0\ (p>0)$
- $\int_0^1\ln x\,dx=-1$ 收敛（分部积分：原函数 $x\ln x-x$）
- $\frac{1}{x^p|\ln x|^q}$ 型：对数因子不改变 $p$ 判别法的结论（$p<1$ 敛）

### 21.4.5 更一般的函数在 0 附近的表现

- 组合函数抓"主导项"：如 $\frac{1-\cos x}{x^3}\sim\frac{x^2/2}{x^3}=\frac{1}{2x}$，$p=1$ 发散
- $e^x-1-x\sim\frac{x^2}{2}$
- $\ln(1+x)\sim x$
- 套路：分子分母分别找等价无穷小，相除得 $x^{-p}$ 型

## 21.5 如何应对不在 0 或 ∞ 处的瑕点

- 平移化归：瑕点在 $x=a$，设 $t=x-a$ 化为 $t=0$ 处的瑕积分
- 例：$\int_0^2\frac{dx}{(x-1)^2}$，设 $t=x-1$ 化为 $\int_{-1}^1\frac{dt}{t^2}$，再从 0 拆开判发散
- 内部瑕点必须拆：$\int_a^b$ 在 $c\in(a,b)$ 处破裂 → $\int_a^c+\int_c^b$，两边各判一次
- 端点瑕：$\int_a^b$ 在 $b$ 处破裂 → $\lim_{t\to b^-}\int_a^t$
- 多个瑕点逐个拆，不要一次想处理完
