# 第11章 导数和图像

本章回答"导数能告诉我们图像什么"：极值定理保证最值存在，罗尔定理和中值定理把函数增量与导数绑在一起，二阶导数刻画凹凸性，最后给出稳定点分类的两套检验法。

## 11.1.1 全局极值和局部极值

- 全局最大值：$f(c)\ge f(x)$ 对定义域内一切 $x$ 成立；全局最小值反之
- 局部极大值：存在 $\delta>0$，使 $f(c)\ge f(x)$ 对 $(c-\delta,c+\delta)$ 内一切 $x$ 成立；局部极小反之
- 局部极值只看邻居，全局极值要看全场；在区间内部取得的全局最值一定也是局部极值
- 极值点指横坐标 $c$，极值指函数值 $f(c)$，写答案时别混用
- 单调函数的最值只能在端点取得，内部不可能有极值
- 端点处取得的全局最值不算局部极值（端点没有"两侧邻居"可比）

## 11.1.2 极值定理

- 条件：$f$ 在闭区间 $[a,b]$ 上连续 → 结论：$f$ 必在 $[a,b]$ 上取得全局最大值和最小值
- 两个条件缺一不可：开区间 $(0,1)$ 上的 $1/x$ 连续但取不到最值；不连续的函数也可能取不到
- 定理只保证"存在"，不告诉你最值在哪——找法见 11.1.3
- 直观理解：闭区间上连续的图像是不断的一笔画，必有最高点和最低点
- 这是"验端点 + 验临界点"求最值方法的理论后盾

## 11.1.3 求全局最大值和最小值

- 术语：稳定点（$f'(c)=0$）、奇点（$f'(c)$ 不存在）、临界点 = 稳定点 + 奇点
- 费马引理：区间内部的局部极值点若可导，则必为稳定点——所以最值候选人只有临界点和端点
- 步骤：①求出 $(a,b)$ 内所有临界点；②算出临界点与端点 $a$、$b$ 的函数值；③比较大小定最大最小
- 易错点：奇点（如尖点 $|x|$ 在 0 处、垂直切线处）也是候选人，别只找 $f'=0$
- 端点本身不可导也无妨，端点永远是候选人，直接算函数值参与比较
- 开区间或无穷区间上没有端点可验：用极限看两端趋势，或先找唯一的局部极值再论证它就是全局最值
- 典型题型 → 解法套路：闭区间求最值 = 找临界点 + 算端点值 + 比大小，三步走

## 11.2 罗尔定理

- 条件：$f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导、且 $f(a)=f(b)$ → 结论：存在 $c\in(a,b)$ 使 $f'(c)=0$
- 几何意义：两端等高的光滑曲线，中间必有一处切线水平
- 三个条件都要验：缺"端点值相等"结论即失效（如 $[0,1]$ 上的 $f(x)=x$ 处处 $f'=1$）
- 证明思路：非常值函数用极值定理在内部取到最值，再用费马引理得导数为零
- 应用：证 $f$ 在 $(a,b)$ 内有零点——构造 $F$ 使 $F'=f$ 且 $F(a)=F(b)$，罗尔定理即给出 $f$ 的零点

## 11.3 中值定理

- 条件：$f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导 → 结论：存在 $c\in(a,b)$ 使 $f'(c)=\dfrac{f(b)-f(a)}{b-a}$
- 几何意义：曲线上必有一点切线平行于端点连线（割线）
- 罗尔定理是中值定理在 $f(a)=f(b)$ 时的特例
- 证明思路：作辅助函数 $g(x)=f(x)-\dfrac{f(b)-f(a)}{b-a}x$ 化成 $g(a)=g(b)$，套罗尔定理
- 推论 1：$f'\equiv 0$ 则 $f$ 为常数（不定积分"差一个常数"的理论依据）
- 推论 2：$f'=g'$ 则 $f-g$ 为常数
- 典型题型 → 解法套路：证不等式如 $|\sin x-\sin y|\le|x-y|$——对 $\sin$ 用中值定理，$|\cos c|\le 1$ 即得

## 11.4 二阶导数和图像

- $f''>0$ → 图像上凹（concave up），切线斜率递增，碗口朝上
- $f''<0$ → 图像下凹（concave down），切线斜率递减，碗口朝下
- 位置关系：上凹时图像在切线上方，下凹时图像在切线下方
- 拐点：凹凸性发生改变的点；$f''(c)=0$ 只是必要条件，必须变号才是拐点
- 反例：$y=x^4$ 在 0 处 $f''=0$，但两侧 $f''>0$ 不变号，所以不是拐点
- 找拐点步骤：解 $f''(x)=0$ 及 $f''$ 不存在的点 → 检查两侧 $f''$ 是否变号 → 变号且函数在该点连续才是拐点

## 11.5.1 使用一次导数

- 一阶导数检验：看稳定点（或奇点）两侧 $f'$ 的符号变化
- $f'$ 由负变正 → 局部最小值；由正变负 → 局部最大值；不变号 → 不是极值（如 $x^3$ 在 0 处）
- 优点：万能，对奇点也适用；缺点：要列表看符号，步骤多一点
- 实操：用 12.1.1 的一阶符号表，一张表同时读出单调性和极值
- 奇点分类示例：$f(x)=|x|$ 在 0 处 $f'$ 由负变正 → 局部最小值，二阶检验对此无能为力

## 11.5.2 使用二阶导数

- 二阶导数检验：设 $f'(c)=0$，则 $f''(c)>0$ → 局部最小值；$f''(c)<0$ → 局部最大值
- $f''(c)=0$ 时判定失效，必须回头用一阶检验（如 $x^4$ 与 $-x^4$ 在 0 处都是 $f''=0$）
- 优点：算一个二阶导数值就行，快；缺点：只适用于稳定点，奇点用不了
- 直观：$f''(c)>0$ 意味着在 $c$ 附近上凹，稳定点只能是碗底
- 选择建议：二阶导好算先用二阶，失效或遇到奇点时换一阶检验
