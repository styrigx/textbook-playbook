# 第14章 洛必达法则及极限问题总结

本章给"算不出"的极限上最后一件兵器——洛必达法则，并把全书的极限方法（代入、因式分解、共轭、特殊极限、洛必达、取对数）汇总成一张作战地图。

## 14.1.1 类型A：0/0

- 条件：$\lim f/g$ 为 $0/0$ 型；$f$、$g$ 在 a 附近可导（a 可为 $\pm\infty$）；$g'(x)\neq 0$；$\lim f'/g'$ 存在（或为无穷）
- 公式：$\displaystyle\lim_{x\to a}\frac{f(x)}{g(x)}=\lim_{x\to a}\frac{f'(x)}{g'(x)}$
- 可连用：一次洛必达后仍是 $0/0$ 就再来一次，直到能算为止
- 每次洛必达前先化简：能约分约分，能提公因式提，别无脑连求三次导
- 不是 $0/0$ 或 $\infty/\infty$ 别用：类型不对时洛必达给出的是错误答案
- 易错点：洛必达求的是导数的比，不是商的导数——$\left(\dfrac{f}{g}\right)'$ 是错的
- $\lim f'/g'$ 不存在（震荡）时洛必达失效，但原极限可能存在（如 $\lim_{x\to\infty}\dfrac{x+\sin x}{x}=1$）

## 14.1.2 类型A：∞/∞

- 条件与 $0/0$ 型相同，只是分子分母都趋于无穷（$\pm\infty$ 皆可，$\infty/-\infty$ 也算）
- 对 $x\to\pm\infty$ 的分式最顺手，但多项式比多项式直接看最高次项更快，不必洛必达
- $\infty/\infty$ 连用同样允许，每次动手前确认类型没变
- 易错点：$\infty-\infty$、$0\times\infty$ 不是 A 型，必须先化归（见 14.1.3、14.1.4）
- 和 9.4.4 配合：带 $e^x$ 的 $\infty/\infty$，洛必达几次后多项式部分会被"吃掉"
- 若化简后极限显然（如约分成常数），不必再洛必达

## 14.1.3 类型B1：(∞-∞)

- 化归套路一：通分——$\infty-\infty$ 的两项通分成一个分式，常化为 $0/0$ 型
- 例：$\dfrac{1}{\sin x}-\dfrac{1}{x}=\dfrac{x-\sin x}{x\sin x}$（$x\to 0$），分子分母都趋于 0
- 化归套路二：提公因式——提主导项，如 $\sqrt{x^2+x}-x$ 提 $x$ 出来
- 有理化是常用特例：$\sqrt{x^2+x}-x$ 乘共轭化成 $\dfrac{x}{\sqrt{x^2+x}+x}$
- 选哪种看长相：分式相减用通分，根号相减用共轭，幂函数相减提主导项
- 通分后若还是 $0/0$ 就接洛必达；若化成别的类型，按对应类型继续化归

## 14.1.4 类型B2：(0×±∞)

- 化归套路：把其中一项"翻下去"变分母——$f\cdot g=\dfrac{f}{1/g}$ 或 $\dfrac{g}{1/f}$，化成 $0/0$ 或 $\infty/\infty$
- 选择原则：翻下去之后求导要好算，通常把幂函数翻下去（如 $x\ln x=\dfrac{\ln x}{1/x}$，$\ln x$ 求导变 $1/x$ 很干净）
- 例：$\lim_{x\to 0^+}x\ln x=\lim_{x\to 0^+}\dfrac{\ln x}{1/x}$（$\infty/\infty$）→ 洛必达得 $\lim\dfrac{1/x}{-1/x^2}=\lim(-x)=0$
- 选错翻法会越算越繁：翻完求导后分母出现高次幂时，换另一种翻法试试
- 化归后接洛必达，一次不够就再来一次，每次确认类型

## 14.1.5 类型C：(1^±∞，0^0 或 ∞^0)

- 化归套路：设 $y=f(x)^{g(x)}$，取对数 $\ln y=g(x)\ln f(x)$ 化成 B2 型（$0\times\infty$）
- 步骤：①取对数；②按 B2 化归 + 洛必达求出 $\lim\ln y=L$；③原极限 $=e^L$
- $1^\infty$ 型：$\lim_{x\to 0}(1+x)^{1/x}$，$\ln y=\dfrac{\ln(1+x)}{x}\to 1$，故极限为 $e$
- $0^0$ 型：$\lim_{x\to 0^+}x^x$，$\ln y=x\ln x\to 0$，故极限为 $1$
- $\infty^0$ 型：$\lim_{x\to\infty}x^{1/x}$，$\ln y=\dfrac{\ln x}{x}\to 0$，故极限为 $1$
- 易错点：最后一步别忘了 $e^L$，$\lim\ln y$ 不是答案；$L$ 为 $\pm\infty$ 时答案为 $\infty$ 或 0
- 三种类型共用一套流程：看到"指数位置趋于无穷或零"就取对数

## 14.1.6 洛必达法则类型的总结

- A 型（$0/0$、$\infty/\infty$）：直接洛必达，可连用
- B1 型（$\infty-\infty$）：通分 / 提公因式 / 有理化 → 化成 A 型
- B2 型（$0\times\infty$）：一项翻下去 → 化成 A 型
- C 型（$1^\infty$、$0^0$、$\infty^0$）：取对数 → 化成 B2 → 化成 A 型
- 决策顺序：先看类型 → 化归到 A → 洛必达（配合化简）→ 指数型最后 $e^L$
- 一句话：洛必达只吃 A 型，其他类型都是想办法变成 A 型

## 14.2 关于极限的总结

- 全书极限工具箱：①直接代入；②因式分解约分；③共轭有理化；④三明治定理；⑤特殊极限（$\sin x/x$、$(e^x-1)/x$、$\ln(1+x)/x$、$(1+1/n)^n$）；⑥洛必达；⑦取对数
- 作战顺序：先直接代入 → 定类型 → 代数变形优先（因式分解/通分/共轭）→ 特殊极限凑形 → 洛必达 → 指数型取对数
- 代数变形优先的原因：洛必达可能把简单题算复杂，且对非 A 型束手无策
- 左右极限：分段函数、绝对值、$0^+$ 处的对数，记得分左右讨论
- 无穷远处：多项式/有理式先看最高次项；$e^x$、$\ln x$ 用 9.4 的增长链 $\ln x \ll x^r \ll e^x$
- 易错清单：洛必达条件没验（分母导数是否为零）、$e^L$ 最后一步漏掉、$\infty-\infty$ 直接洛必达、$\ln$ 的真数定义域
- 极限不存在的情形：左右极限不等、震荡（如 $\sin(1/x)$ 在 0 处）、发散到无穷
- 终极建议：做完后代个特殊值或画个图直觉验算，数量级不对立刻回头检查
