# 第12章 绘制函数图像

本章把前面的导数工具组装成"画图流水线"：先学会建立一阶、二阶导数的符号表格，再按"定义域→截距→对称性→渐近线→两张符号表→落图"七步画出函数图像。

## 12.1.1 建立一阶导数的符号表格

- 一阶符号表的分区点：$f'=0$ 的稳定点、$f'$ 不存在的奇点、$f$ 本身的定义域断点
- 步骤：①求 $f'$ 并找全部分区点；②按大小排序画数轴；③每区间任取测试点定 $f'$ 符号；④标增减箭头
- $f'>0$ → 递增（↗），$f'<0$ → 递减（↘），箭头方向就是图像走势
- 分区点处的取值单独算：连续则标出函数值，断点处标左右极限
- 符号改变处即局部极值：$-$ 变 $+$ 为极小，$+$ 变 $-$ 为极大
- 易错点：定义域断点（如分母为零处）也要拿来分区，$f'$ 在断点两侧符号可能不同
- 一张表同时回答单调性和极值，绘图前必做

## 12.1.2 建立二阶导数的符号表格

- 二阶符号表的分区点：$f''=0$ 的点、$f''$ 不存在的点、$f$ 的定义域断点
- 步骤与一阶表相同：排序分区 → 测试点定号 → 标凹凸
- $f''>0$ → 上凹，$f''<0$ → 下凹
- 凹凸改变且函数在该点连续的分区点即拐点，在表上做记号
- 易错点：$f''=0$ 但不变号不是拐点；函数不连续的点（如渐近线处）再怎么"变号"也不是拐点
- 拐点必须同时满足：在定义域内 + 两侧凹凸性相反
- 一阶表管"上下走"，二阶表管"弯腰方向"，两张表合起来图像基本定型

## 12.2 绘制函数图像的全面方法

- 七步：①定义域；②截距；③对称性；④渐近线；⑤一阶符号表；⑥二阶符号表；⑦描点画图
- 定义域：分母不为零、偶次根号下非负、对数真数为正；断点是垂直渐近线的候选
- 截距：y 截距算 $f(0)$，x 截距解 $f(x)=0$
- 对称性：偶函数 $f(-x)=f(x)$ 关于 y 轴对称；奇函数关于原点对称；周期函数画一个周期即可
- 垂直渐近线：在定义域断点处看左右极限，趋于 $\pm\infty$ 即是
- 水平渐近线：算 $\lim_{x\to\pm\infty}f(x)$，左端右端分开算，结果可能不同
- 斜渐近线：分子比分母高一次的有理函数，$m=\lim_{x\to\pm\infty}\dfrac{f(x)}{x}$，$b=\lim_{x\to\pm\infty}(f(x)-mx)$，渐近线为 $y=mx+b$
- 易错点：图像可以穿过水平/斜渐近线（渐近线只管无穷远处），但不能穿过垂直渐近线（那是定义域禁区）
- 落图：描出截距、极值点、拐点等关键点，用单调性和凹凸性把它们连起来

## 12.3.1 一个不使用导数的例子

- 演示：不依赖导数也能画的函数——有理函数靠"四件套"（定义域、截距、对称性、渐近线）即可定型
- 步骤：找定义域断点 → 定垂直渐近线 → 算 $\pm\infty$ 极限定水平渐近线 → 求截距 → 分区间定正负 → 草图
- 典型题型 → 解法套路：分式函数先因式分解，约分前后的"洞"（可去间断点）要标出来
- 约分后消失的因子对应的是"洞"不是渐近线，别把两者搞混
- 何时够用：只需大致形状、不考极值拐点时，这套流程最快

## 12.3.2 完整的方法：例一

- 第一次七步全开的实战：从定义域一路做到二阶符号表再落图
- 体会"表格先行、画图在后"的顺序：所有关键点先算出来，画图只是连线
- 检查清单：分区点找全了吗？渐近线画了吗？极值点和拐点在图上标出来了吗？
- 易错点：求导后不化简直接找零点，会把简单方程算成难题；商法则的结果先通分化简
- 画图顺序建议：先画渐近线（虚线），再描关键点，最后按单调凹凸连线

## 12.3.3 完整的方法：例二

- 第二次实战：分区点更多、计算量更大的情形，重点练表格的完整性
- 指数、对数型函数的两端行为要分开算（如 $e^{-x}$ 在 $+\infty$ 与 $-\infty$ 处迥异）
- 求导时 $e^{(\cdot)}$ 的导数保留 $e^{(\cdot)}$ 因子再提公因式，零点一目了然
- 若 $f''=0$ 实在解不出，先保证一阶表正确，凹凸性可用数值测试点估计
- 画完后用几个特殊点的函数值验算，确认图像位置没画反

## 12.3.4 完整的方法：例三

- 第三次实战：含特殊点（定义域断点、不可导点）的情形
- 分段点、尖点（奇点）要进一阶符号表的分区点，极值可能就藏在奇点处
- 绝对值函数先按零点分段去绝对值，再分段求导、分别画图
- 定义域端点处的单侧极限决定图像"从哪里开始、到哪里结束"，别画出界

## 12.3.5 完整的方法：例四

- 收官例子：综合性最强，极值点、拐点、渐近线可能同时出现
- 分区点多时表格要画整齐，漏一个分区点整张图走样
- 终极检查：极值点个数与 $f'=0$ 解的个数对得上吗？拐点两侧凹凸真变号了吗？
- 养成习惯：画完回头用"定义域→渐近线→关键点"三步复查一遍
