# 第15章 积分

本章是积分的"热身"：先学求和记号（含伸缩求和），再从"速度—位移—面积"的故事理解积分为什么是求和的极限。

## 15.1.1 一个有用的求和

- 求和记号：$\sum_{k=1}^n a_k=a_1+a_2+\cdots+a_n$，k 是哑指标，换成 j、i 都一样
- 线性性质：$\sum(c\,a_k)=c\sum a_k$，$\sum(a_k\pm b_k)=\sum a_k\pm\sum b_k$
- $\sum_{k=1}^n 1=n$，$\sum_{k=1}^n c=cn$
- $\sum_{k=1}^n k=\dfrac{n(n+1)}{2}$（高斯配对：首尾相加）
- $\sum_{k=1}^n k^2=\dfrac{n(n+1)(2n+1)}{6}$
- $\sum_{k=1}^n k^3=\left[\dfrac{n(n+1)}{2}\right]^2$（恰好是前 n 个自然数之和的平方）
- 指标平移：$\sum_{k=0}^{n-1}(k+1)=\sum_{k=1}^n k$，换元时上下限要跟着变

## 15.1.2 伸缩求和法

- 伸缩求和：$\sum_{k=1}^n(a_k-a_{k+1})=a_1-a_{n+1}$，中间项两两相消
- 本质：离散版的微积分基本定理（"差分的和 = 端点值的差"），16 章会呼应
- 裂项：$\dfrac{1}{k(k+1)}=\dfrac{1}{k}-\dfrac{1}{k+1}$，分式求和先裂项再伸缩
- 例：$\sum_{k=1}^n\dfrac{1}{k(k+1)}=1-\dfrac{1}{n+1}=\dfrac{n}{n+1}$
- 更一般的裂项：$\dfrac{1}{k(k+2)}=\dfrac{1}{2}\left(\dfrac{1}{k}-\dfrac{1}{k+2}\right)$，系数别漏
- 易错点：伸缩后剩下的是首项和"第 n+1 项"，不是第 n 项

## 15.2.1 三个简单的例子

- 匀速运动：速度恒为 v，时间 t 内位移 $=v\times t$，恰好是 v-t 图像下矩形的面积
- 三个例子分别对应：正速度、负速度、速度有正有负——位移 = 面积的代数和
- 核心洞察：位移 = v-t 图像与 t 轴围成的"有向面积"
- 负速度对应 t 轴下方的矩形，面积记为负（往回走抵消位移）
- 这是定积分定义的物理原型：面积 = 求和 = 积分

## 15.2.2 一段更常规的旅行

- 变速但分段匀速：每段时间速度恒定，总位移 = 各段 $v_k\Delta t_k$ 之和
- 图像是阶梯函数，位移 = 阶梯下小矩形的有向面积之和
- 分段越细（每段 $\Delta t$ 越小），阶梯越贴近真实连续变化的速度曲线
- 求和式 $\sum v_k\Delta t_k$ 就是黎曼和的雏形
- 思想：复杂运动切成小段，每小段按匀速近似，再加起来

## 15.2.3 有向面积

- 有向面积：x 轴（t 轴）上方为正，下方为负；位移 = 有向面积，路程 = 面积的绝对值之和
- 例：v-t 图像一半在上、一半在下，位移可能为零，但路程是两部分面积相加
- 几何意义：定积分 $\int_a^b f$ 算的是有向面积，不是"总面积"
- 求"总面积/路程"时要先找零点分段，对每段取绝对值再相加（见 16.4.1）
- 对称性可秒杀：奇函数在对称区间上的有向面积为零
- 易错点：题目问"面积"通常指总面积（非负），问"位移/积分"才用有向面积

## 15.2.4 连续的速度

- 速度连续变化时矩形近似不再精确：每小段内速度本身也在变
- 办法：把时间切成 n 个小段，每段用左端点（或右端点）速度近似，总位移 $\approx\sum v(t_k)\Delta t$
- n 越大、$\Delta t$ 越小，近似越好；$n\to\infty$ 时近似变成精确值
- 极限 $\lim_{n\to\infty}\sum v(t_k)\Delta t$ 就是定积分 $\int_a^b v(t)\,dt$
- 连续性保证：$v$ 连续时左端点、右端点、中点近似的极限都相同（函数可积）
- 从"求和"到"积分"只差一个极限，这是 16.2 定义的直观来源

## 15.2.5 两个特别的估算

- 上和与下和：单调函数在每小段上用最大值/最小值作矩形高，得到积分的上、下估计
- 左端点 vs 右端点：递增函数左端点给出下和、右端点给出上和；递减函数反之
- 夹逼：下和 $\le$ 真实值 $\le$ 上和，n 越大两和越接近，极限即积分值
- 中点近似通常比端点近似准（误差相消），但计算稍繁
- 估算的意义：在学"怎么算积分"之前，先知道积分值被夹在什么范围
- 易错点：上和/下和取决于函数在小段上的单调性，不是固定用左端点或右端点
