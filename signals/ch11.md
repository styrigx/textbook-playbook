# 第11章 线性反馈系统

导读：本章把前两章的系统函数工具用于闭环反馈：先看反馈的用途与风险，再用根轨迹看闭环极点随增益的移动、用奈奎斯特判据判定闭环稳定性，最后用增益/相位裕度量化稳定程度。这是连续与离散两套工具在反馈问题上的汇合点。

## 11.0 引言

- 反馈 = 把输出的一部分送回输入端，与输入相减（负反馈）或相加（正反馈）后再进入前向通路。
- 本章只讨论线性时不变反馈系统，分析工具是第 9、10 章的拉普拉斯/z 变换与系统函数。
- 核心矛盾：反馈能改善系统性能（稳定化、补偿非理想、跟踪），但也可能把稳定系统变不稳定。
- 分析主线：反馈的应用 → 根轨迹（极点如何随增益移动）→ 奈奎斯特判据（闭环稳定吗）→ 裕度（离不稳定多远）。
- 连续时间用 s 平面，离散时间用 z 平面，结论形式对偶（右半平面 ↔ 单位圆外）。

## 11.1 线性反馈系统

- 标准负反馈结构：前向通路 $G(s)$，反馈通路 $H(s)$，反馈信号与输入相减。
- 闭环系统函数：$$Q(s)=\frac{G(s)}{1+G(s)H(s)}$$
- 开环系统函数（断开反馈环一周的增益）：$G(s)H(s)$，记作 $L(s)$。
- 闭环极点 = $1+G(s)H(s)=0$ 的根；闭环零点 = $G(s)$ 的零点加上 $H(s)$ 的极点（在 $Q(s)$ 化简前）。
- 本章约定为负反馈：分母是 $1+G(s)H(s)$；若写成 $1-GH$ 则为正反馈约定，读题时先确认符号。
- 反馈的核心思想：用环路增益 $G(s)H(s)$ 的大小来"压制"前向通路的不确定性。

## 11.2 反馈的某些应用及结果

### 11.2.1 逆系统设计

- 若想实现 $G(s)$ 的逆系统 $1/G(s)$，把 $G(s)$ 放在反馈通路、主通路用大增益 $K$，闭环 $\frac{K}{1+KG(s)}\approx\frac{1}{G(s)}$（$|KG|\gg 1$ 时）。
- 本质：高环路增益下闭环特性主要由反馈通路决定，对前向通路的不精确不敏感。
- 条件是闭环必须稳定（高增益下需用奈奎斯特/根轨迹验算）。

### 11.2.2 非理想元件的补偿

- 前向放大器增益不准、非线性时，加负反馈可降低增益对元件参数的敏感度：闭环增益相对变化 $\approx$ 开环相对变化除以 $(1+GH)$。
- 代价：牺牲了开环增益（增益换精度/线性度），这是反馈设计的典型 trade-off。
- 反馈不能补偿反馈通路本身的不理想，所以 $H(s)$ 通常用精密无源元件实现。

### 11.2.3 不稳定系统的稳定

- 开环不稳定的 $G(s)$（极点在右半平面）可通过适当反馈 $H(s)$ 把闭环极点拉回左半平面。
- 例：$G(s)=1/(s-a)$（$a>0$ 不稳定），单位反馈下闭环极点为 $a-K$，取 $K>a$ 即稳定。
- 判据工具：根轨迹看极点移动路径，奈奎斯特判据判定最终稳定性。

### 11.2.4 采样数据反馈系统

- 反馈环中含采样器/保持器的混合系统：连续被控对象 + 离散控制器。
- 分析方法：把连续部分离散化（或把离散部分等效），统一到 z 域用离散反馈理论处理。
- 稳定性边界从 s 平面虚轴换成 z 平面单位圆，奈奎斯特围线也相应改变（见 11.4.3）。

### 11.2.5 跟踪系统

- 跟踪 = 输出尽可能复现输入（伺服问题），反馈通过比较输出与期望来驱动误差趋零。
- 增大环路增益可减小稳态跟踪误差，但过大会导致不稳定，设计要在"跟得准"与"稳得住"之间折中。
- 积分环节（$1/s$）能消除阶跃输入的稳态误差，是跟踪系统的常用手段。

### 11.2.6 反馈引起的不稳定

- 反馈的最大风险：原本稳定的开环系统，闭上环后可能不稳定。
- 机理：某频率下环路增益 $|GH|=1$ 且相位 $=-180°$ 时，负反馈变正反馈，信号被不断放大。
- 这正是奈奎斯特判据要捕捉的情形：$G(j\omega)H(j\omega)$ 包围 $-1$ 点。
- 设计准则：保证足够的增益裕度与相位裕度（见 11.5），不要只看标称稳定性。

## 11.3 线性反馈系统的根轨迹分析法

### 11.3.1 一个例子

- 例：$G(s)H(s)=\frac{K}{s(s+1)}$，闭环极点为 $s=\frac{-1\pm\sqrt{1-4K}}{2}$，随 $K$ 从 0 增大，极点从 $0,-1$ 出发相向移动、汇合后沿虚线进入复平面。
- 直观展示根轨迹的思想：$K$ 连续变化时，闭环极点在 s 平面上画出的轨迹。
- 从例子可见：增益增大会先改善响应速度，但过大会使极点进入右半平面导致不稳定。

### 11.3.2 闭环极点方程

- 闭环极点满足特征方程：$$1+KG(s)H(s)=0$$（设 $G(s)H(s)=K\cdot G_0(s)H_0(s)$，$K$ 为可调增益，常取 $K>0$）。
- 写成 $G(s)H(s)=-1/K$ 后分解为角判据与模判据两条。
- 根轨迹 = $K$ 从 $0$ 变到 $+\infty$（或 $-\infty$）时特征方程所有根的轨迹。
- 轨迹上的每一点都对应某个 $K$ 值下闭环系统的一个极点。

### 11.3.3 根轨迹的端点：K=0和|K|=∞时的闭环极点

- $K=0$ 时：$1+0=0$ 无意义，取极限得闭环极点 = 开环极点（$G(s)H(s)$ 的极点），这是每条分支的起点。
- $|K|\to\infty$ 时：$G(s)H(s)\to 0$，闭环极点趋向开环零点（$G(s)H(s)$ 的零点），这是分支的终点。
- 分支总数 = 开环极点数 $n$；其中 $m$ 条终止于有限零点，$n-m$ 条趋向无穷远。
- 趋向无穷的分支沿渐近线方向（见 11.3.5）。
- $K<0$（正反馈情形）的根轨迹规则类似但角判据变为 $2k\pi$，实轴判据左右互换。

### 11.3.4 角判据

- $K>0$ 时，$s$ 在根轨迹上 ⟺ 角判据成立：$$\angle G(s)H(s)=(2k+1)\pi,\quad k=0,\pm1,\pm2,\dots$$
- 模判据：$|KG(s)H(s)|=1$，用于确定轨迹上某点对应的 $K$ 值：$K=1/|G(s)H(s)|$。
- 角判据只与 $G(s)H(s)$ 的零极点位置有关，与 $K$ 无关，所以画轨迹先用角判据定形状，再用模判据标 $K$。
- $K<0$ 时角判据为 $\angle G(s)H(s)=2k\pi$（相差 $180°$）。
- 实轴上线段判据（$K>0$）：实轴上某段属于根轨迹 ⟺ 其右侧的实数开环零极点总数为奇数（零极点角度各贡献 $180°$ 或 $0°$）。

### 11.3.5 根轨迹的性质

- 对称性：根轨迹关于实轴对称（复极点共轭成对出现）。
- 渐近线：$n-m$ 条趋向无穷的分支沿渐近线，渐近线交于实轴上一点 $$\sigma_a=\frac{\sum_{i=1}^{n}p_i-\sum_{j=1}^{m}z_j}{\,n-m\,}$$ 角度为 $\frac{(2k+1)\pi}{\,n-m\,}$（$K>0$），$k=0,\dots,n-m-1$。
- 分离点/汇合点：多条分支在实轴上分离（或汇合）之处，满足 $$\sum_{i=1}^{n}\frac{1}{d-p_i}=\sum_{j=1}^{m}\frac{1}{d-z_j}$$ 解出的实数 $d$ 再用角判据筛选。
- 与虚轴交点：用劳斯判据或令 $s=j\omega$ 代入特征方程求解，交点对应的 $K$ 即稳定临界增益。
- 出射角/入射角：从复数开环极点出发的分支切线方向 = $180°$ 减去其他零极点到该点的角度贡献（角判据的局部应用）。
- 根轨迹的用途：选 $K$ 使闭环极点落在期望区域（左半平面、足够阻尼比），是经典的控制器设计工具。

## 11.4 奈奎斯特稳定判据

### 11.4.1 围线性质

- 围线原理：$F(s)$ 解析，沿 s 平面闭合围线 $\Gamma_s$ 顺时针走一圈，$F(s)$ 在 $F$ 平面的像 $\Gamma_F$ 顺时针包围原点的圈数 $N=Z-P$。
- $Z$ 为 $\Gamma_s$ 内 $F(s)$ 的零点数，$P$ 为极点数（计重数），$N$ 为 $\Gamma_F$ 顺时针包围原点的净圈数。
- 取 $F(s)=1+G(s)H(s)$，则 $F$ 的零点 = 闭环极点，$F$ 的极点 = 开环极点。
- 围线 $\Gamma_s$ 取包围整个右半平面的奈奎斯特围线（虚轴 + 无穷大半圆，绕过虚轴上的极点）。

### 11.4.2 连续时间线性时不变反馈系统的奈奎斯特判据

- 记 $Z$ 为闭环系统在右半平面的极点数，$P$ 为开环 $G(s)H(s)$ 在右半平面的极点数，$N$ 为 $G(j\omega)H(j\omega)$（$\omega$ 从 $-\infty$ 到 $+\infty$）顺时针包围 $-1$ 点的圈数。
- 奈奎斯特稳定判据：$$Z=N+P$$
- 闭环稳定 ⟺ $Z=0$ ⟺ $N=-P$（即 $G(j\omega)H(j\omega)$ 逆时针包围 $-1$ 点 $P$ 圈）。
- 最常用的特例：开环稳定（$P=0$）时，闭环稳定 ⟺ $G(j\omega)H(j\omega)$ 不包围 $-1$ 点。
- $-1$ 点的含义：$G(j\omega)H(j\omega)=-1$ 即 $1+GH=0$，对应闭环极点落在虚轴上（稳定边界）。
- 作图技巧：$\omega$ 从 $0^+$ 到 $+\infty$ 画一半，利用共轭对称补全；虚轴上有开环极点时围线要绕行（小半圆绕过），映射曲线相应出现无穷大半圆。
- 易错点：$N$ 的正负号（顺时针为正）与 $Z=N+P$ 的对应关系；包围 $-1$ 点指的是 $GH$ 平面，不是 $1+GH$ 平面（后者包围的是原点）。

### 11.4.3 离散时间线性时不变反馈系统的奈奎斯特判据

- 离散时间稳定区域是单位圆内（对偶于 s 平面的左半平面），奈奎斯特围线取单位圆（$z=e^{j\omega}$，$\omega$ 从 $-\pi$ 到 $\pi$）。
- 判据形式相同：$Z=N+P$，其中 $Z$ 为闭环在单位圆外的极点数，$P$ 为开环在单位圆外的极点数，$N$ 为 $G(e^{j\omega})H(e^{j\omega})$ 顺时针包围 $-1$ 点的圈数。
- 闭环稳定 ⟺ $Z=0$。
- 开环稳定（$P=0$）时：闭环稳定 ⟺ $G(e^{j\omega})H(e^{j\omega})$ 不包围 $-1$ 点。
- 对偶记忆：把 11.4.2 的"右半平面"换成"单位圆外"、"$j\omega$ 轴"换成"单位圆"，公式不变。

## 11.5 增益和相位裕度

- 裕度 = 衡量闭环系统离不稳定有多远，定义在开环频率响应 $G(j\omega)H(j\omega)$ 上。
- 增益裕度：相频 $\angle G(j\omega)H(j\omega)=-180°$ 的频率（相位穿越频率）处，$$GM=\frac{1}{|G(j\omega)H(j\omega)|}$$ 常用分贝 $20\log_{10}GM$。
- 相位裕度：$|G(j\omega)H(j\omega)|=1$ 的频率（增益穿越频率）处，$$PM=\angle G(j\omega)H(j\omega)-(-180°)=\angle GH+180°$$
- 稳定要求（开环稳定、最小相位常见情形）：$GM>1$（$>0$dB）且 $PM>0$；工程常用 $GM\ge 6$dB、$PM\ge 30°\sim 60°$。
- $PM$ 越大，阶跃响应超调越小、阻尼越好；$PM$ 与时域性能有近似对应关系。
- 伯德图上读裕度：增益裕度看相频过 $-180°$ 处幅频离 0dB 的距离，相位裕度看幅频过 0dB 处相频离 $-180°$ 的距离。
- 易错点：裕度只在"穿越频率存在且系统为最小相位/开环稳定"时才有常规意义，非最小相位系统可能裕度为正仍不稳定，需回奈奎斯特判据。

## 11.6 小结

- 反馈闭环 $Q(s)=G(s)/(1+G(s)H(s))$：高环路增益下性能由反馈通路决定，但可能引入不稳定。
- 根轨迹用角判据 $\angle GH=(2k+1)\pi$ 画闭环极点随 $K$ 的轨迹，起点在开环极点、终点在开环零点（或无穷远），是选增益的设计工具。
- 奈奎斯特判据 $Z=N+P$ 用开环频率响应包围 $-1$ 的圈数判定闭环稳定性，连续/离散形式对偶（右半平面 ↔ 单位圆外）。
- 增益裕度与相位裕度量化稳定程度，是工程设计中"留余量"的依据。
- 全章是第 9、10 章工具的综合应用：极点位置决定稳定，ROC/围线的思想一脉相承。
