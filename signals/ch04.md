# 第4章 连续时间傅里叶变换

导读：把第 3 章的周期信号级数推广到非周期信号——让周期 $T\to\infty$，离散的谐波谱线变成连续的频谱，得到傅里叶变换对；解决非周期信号的频域表示、LTI 系统频域分析与滤波问题。

## 4.0 引言

- 第 3 章处理周期信号（离散谱线）；本章处理非周期信号（连续谱）。
- 核心思想：把非周期信号看作周期 $T\to\infty$ 的周期信号的极限。
- 当 $T\to\infty$，基波频率 $\omega_0=2\pi/T\to 0$，谐波间隔趋于 0，离散求和变为积分。
- 本章建立正/反变换对、性质表、卷积/相乘定理，并把 3.8 的 $b_k=H a_k$ 推广为 $Y(j\omega)=X(j\omega)H(j\omega)$。
- 周期信号也可用冲激串纳入变换框架（4.2），使 CTFT 成为统一工具。

## 4.1 非周期信号的表示：连续时间傅里叶变换

### 4.1.1 非周期信号傅里叶变换表示的导出

- 取非周期 $x(t)$，构造周期 $\tilde{x}(t)$：在一个周期 $[-T/2,T/2]$ 内等于 $x(t)$，再周期延拓。
- $\tilde{x}(t)$ 的傅里叶系数：$a_k=\frac{1}{T}\int_{-T/2}^{T/2}\tilde{x}(t)e^{-jk\omega_0 t}dt=\frac{1}{T}X(jk\omega_0)$，其中 $X(j\omega)=\int_{-\infty}^{\infty}x(t)e^{-j\omega t}dt$。
- 综合公式改写：$\tilde{x}(t)=\sum_k \frac{1}{T}X(jk\omega_0)e^{jk\omega_0 t}=\frac{1}{2\pi}\sum_k X(jk\omega_0)e^{jk\omega_0 t}\omega_0$。
- 令 $T\to\infty$：$\omega_0\to d\omega$，求和 $\to$ 积分，得到反变换。
- 傅里叶变换对：$$X(j\omega)=\int_{-\infty}^{\infty}x(t)e^{-j\omega t}dt,\qquad x(t)=\frac{1}{2\pi}\int_{-\infty}^{\infty}X(j\omega)e^{j\omega t}d\omega$$
- $X(j\omega)$ 称为频谱（傅里叶变换）；$|X(j\omega)|$ 幅度谱，$\angle X(j\omega)$ 相位谱。
- $X(j\omega)$ 的量纲是 $x(t)$ 的量纲 × 时间（如伏特·秒），与无量纲的 $a_k$ 不同——正是 $T\to\infty$ 时 $Ta_k\to X$ 的自然结果。
- 易错点：正变换无 $1/2\pi$、反变换有；正变换指数为负——与 CTFS 分析/综合公式的符号约定一致。

### 4.1.2 傅里叶变换的收敛

- 狄里赫利条件（充分）：$x(t)$ 绝对可积 $\int_{-\infty}^{\infty}|x(t)|dt<\infty$；在任何有限区间内只有有限个极值点和间断点，且间断点处函数值有限。
- 有限能量条件 $\int_{-\infty}^{\infty}|x(t)|^2dt<\infty$ 是另一组充分条件（平方可积），保证均方收敛。
- 收敛含义：连续点处反变换积分收敛到 $x(t)$；间断点处收敛到左右极限的平均值。
- 冲激 $\delta(t)$ 等广义信号不满足绝对可积，但可用极限/对偶性定义其变换（$\delta(t)\leftrightarrow 1$）。
- 周期信号（能量无穷）用冲激串纳入变换框架，见 4.2。
- 实际应用：工程信号几乎都满足条件，可直接查表使用变换对。

### 4.1.3 连续时间傅里叶变换举例

- 矩形脉冲：$x(t)=1\ (|t|<T_1)$，$0$ 其他 $\leftrightarrow X(j\omega)=\frac{2\sin(\omega T_1)}{\omega}$（采样函数形）。
- 推导：直接积分 $\int_{-T_1}^{T_1}e^{-j\omega t}dt$；$T_1$ 越大时域越宽，频域主瓣越窄——时宽带宽积守恒的实例。
- 单边指数：$e^{-at}u(t)\ (a>0)\leftrightarrow \frac{1}{a+j\omega}$；推导为 $\int_0^{\infty}e^{-(a+j\omega)t}dt$，$a>0$ 保证收敛，$a\le 0$ 时积分发散。
- 单边指数的幅度谱 $1/\sqrt{a^2+\omega^2}$，相位谱 $-\arctan(\omega/a)$。
- $\delta(t)\leftrightarrow 1$：冲激包含所有频率的等幅分量。
- $u(t)$ 的变换不在此直接积分得到，用 4.3.4 的积分性质由 $\delta(t)$ 推出。
- 方法：直接积分求基本对；复杂信号拆成熟悉分量再用性质（4.3）组合。

## 4.2 周期信号的傅里叶变换

- 周期信号的 CTFS：$x(t)=\sum_k a_k e^{jk\omega_0 t}$；而 $e^{j\omega_0 t}\leftrightarrow 2\pi\delta(\omega-\omega_0)$。
- 由线性得周期信号的傅里叶变换：$$\sum_{k=-\infty}^{\infty}a_k e^{jk\omega_0 t}\longleftrightarrow 2\pi\sum_{k=-\infty}^{\infty}a_k\delta(\omega-k\omega_0)$$
- 物理意义：周期信号的频谱是离散冲激串，冲激强度 $2\pi a_k$ 正比于傅里叶系数。
- 基本对：$e^{j\omega_0 t}\leftrightarrow 2\pi\delta(\omega-\omega_0)$；$\cos(\omega_0 t)\leftrightarrow \pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$；$\sin(\omega_0 t)\leftrightarrow \frac{\pi}{j}[\delta(\omega-\omega_0)-\delta(\omega+\omega_0)]$。
- 常数 $1\leftrightarrow 2\pi\delta(\omega)$（$\omega_0=0$ 的特例）。
- 周期冲激串 $\sum_k\delta(t-kT)\leftrightarrow \frac{2\pi}{T}\sum_k\delta(\omega-k\frac{2\pi}{T})$：时域冲激串 $\leftrightarrow$ 频域冲激串（采样定理的理论基础之一）。
- 由此 CTFS 与 CTFT 统一：CTFT 是更一般的框架，CTFS 是其在周期信号上的特例。
- 易错点：冲激前的系数是 $2\pi a_k$ 不是 $a_k$；$\cos$ 的两个冲激各带 $\pi$。

## 4.3 连续时间傅里叶变换性质

### 4.3.1 线性性质

- $ax(t)+by(t)\leftrightarrow aX(j\omega)+bY(j\omega)$，成立条件是各变换都存在。
- 应用：信号分解为已知变换对的线性组合，逐项变换再叠加。

### 4.3.2 时移性质

- 时移：$x(t-t_0)\leftrightarrow e^{-j\omega t_0}X(j\omega)$——只引入线性相位，幅度谱不变。
- 频移（调制）：$e^{j\omega_0 t}x(t)\leftrightarrow X(j(\omega-\omega_0))$——时域乘复指数 $\leftrightarrow$ 频域平移。
- $\cos(\omega_0 t)x(t)$ 的谱是 $X$ 左右平移 $\omega_0$ 后取半叠加——调幅（AM）的数学基础。
- 易错点：时移因子 $e^{-j\omega t_0}$ 的负号；频移是 $X(j(\omega-\omega_0))$，乘 $e^{+j\omega_0 t}$ 对应谱向右移。

### 4.3.3 共轭与共轭对称性

- $x^*(t)\leftrightarrow X^*(-j\omega)$。
- $x(t)$ 为实信号 $\iff X(j\omega)=X^*(-j\omega)$（共轭对称）：$|X(j\omega)|$ 偶对称，$\angle X(j\omega)$ 奇对称。
- 实偶信号 $\implies X(j\omega)$ 实偶；实奇信号 $\implies X(j\omega)$ 纯虚奇。
- 分解对应：$x(t)$ 的偶部 $\leftrightarrow \mathrm{Re}\{X(j\omega)\}$，奇部 $\leftrightarrow j\,\mathrm{Im}\{X(j\omega)\}$。
- 应用：实信号只需画 $\omega\ge 0$ 的频谱；可用幅度谱的偶对称性检验计算错误。

### 4.3.4 微分与积分

- 时域微分：$\frac{dx}{dt}\leftrightarrow j\omega X(j\omega)$；$n$ 阶：$\frac{d^n x}{dt^n}\leftrightarrow (j\omega)^n X(j\omega)$。
- 成立条件：$x(t)$ 连续可微且变换存在；对间断信号微分会产生冲激项（如 $u(t)$ 的导数是 $\delta(t)$）。
- 频域微分：$(-jt)^n x(t)\leftrightarrow \frac{d^n}{d\omega^n}X(j\omega)$。
- 时域积分：$$\int_{-\infty}^{t}x(\tau)d\tau\longleftrightarrow \frac{1}{j\omega}X(j\omega)+\pi X(0)\delta(\omega)$$
- 积分公式中 $\pi X(0)\delta(\omega)$ 补偿直流（平均值）经积分变成阶跃趋势的部分；$X(0)=0$（零均值）时退化为除以 $j\omega$。
- 应用：微分方程 $\to$ 代数方程（4.7 的理论依据）；$u(t)$ 的变换由 $\delta(t)$ 积分得到：$u(t)\leftrightarrow \frac{1}{j\omega}+\pi\delta(\omega)$。
- 易错点：积分性质漏掉 $\pi X(0)\delta(\omega)$ 项是最常见的错；$u(t)$ 的变换不是 $1/j\omega$。

### 4.3.5 时间与频率的尺度变换

- $x(at)\leftrightarrow \frac{1}{|a|}X(j\omega/a)$（$a\ne 0$）。
- $|a|>1$ 时域压缩 $\to$ 频域展宽且幅度降低 $1/|a|$（能量守恒的体现）。
- $a=-1$ 为时间反转：$x(-t)\leftrightarrow X(-j\omega)$。
- 时宽带宽积：信号在时域越集中，频域越分散——不确定性原理的信号版本。
- 易错点：幅度因子 $1/|a|$ 常被漏掉；注意是 $|a|$ 不是 $a$。

### 4.3.6 对偶性

- 若 $x(t)\leftrightarrow X(j\omega)$，则 $$X(jt)\longleftrightarrow 2\pi x(-j\omega)$$
- 含义：时域与频域角色互换（差一个 $2\pi$ 因子与一次反转）。
- 应用：已知矩形脉冲 $\leftrightarrow$ 采样函数，立即得时域采样函数 $\frac{\sin(Wt)}{\pi t}\leftrightarrow$ 频域矩形（$|\omega|<W$ 时为 1，即理想低通）。
- 易错点：$2\pi$ 因子与 $-j\omega$ 中的负号；对偶的是 $X(jt)$（把频域函数当作时间函数）。

### 4.3.7 帕斯瓦尔定理

- $$\int_{-\infty}^{\infty}|x(t)|^2dt=\frac{1}{2\pi}\int_{-\infty}^{\infty}|X(j\omega)|^2d\omega$$
- 左边是信号总能量，右边是能量谱密度 $|X(j\omega)|^2$ 在全频域的积分——能量守恒。
- $|X(j\omega)|^2$ 称为能量谱密度：$|X|^2 d\omega/(2\pi)$ 是 $d\omega$ 频带内的能量。
- 广义形式：$\int_{-\infty}^{\infty}x_1(t)x_2^*(t)dt=\frac{1}{2\pi}\int_{-\infty}^{\infty}X_1(j\omega)X_2^*(j\omega)d\omega$。
- 应用：在频域算能量（如滤波后剩余能量占比）常比时域积分容易。
- 与 CTFS 帕斯瓦尔对比：周期信号谈平均功率（$1/T$ 归一），非周期信号谈总能量（$1/2\pi$ 归一）。

## 4.4 卷积性质

- 时域卷积 $\leftrightarrow$ 频域相乘：$$y(t)=x(t)*h(t)\longleftrightarrow Y(j\omega)=X(j\omega)H(j\omega)$$
- 这是 LTI 系统频域分析的核心：$H(j\omega)$ 既是特征值（3.2），又是 $h(t)$ 的傅里叶变换。
- 方法步骤：求 $X$、$H$ → 相乘得 $Y$ → 反变换得 $y(t)$，避开时域卷积积分。
- $H(j\omega)$ 称为频率响应：$|H|$ 幅频特性，$\angle H$ 相频特性；滤波器设计就是设计 $H(j\omega)$ 的形状。

### 4.4.1 举例

- 例：理想低通 $H(j\omega)=1\ (|\omega|<\omega_c)$ 的冲激响应 $h(t)=\frac{\sin(\omega_c t)}{\pi t}$（由对偶性直接得）。
- $h(t)$ 非因果、无限长——理想低通物理不可实现，只能近似。
- 例：带限信号通过理想低通，输出谱 $Y$ 是 $X$ 的截断，$y(t)$ 为保留频率分量的加权和。
- 例：用卷积性质求 $e^{-at}u(t)*u(t)$：$Y(j\omega)=\frac{1}{a+j\omega}\left(\frac{1}{j\omega}+\pi\delta(\omega)\right)$，反变换得 $y(t)=\frac{1-e^{-at}}{a}u(t)$（注意 $\delta(\omega)$ 项与 $1/j\omega$ 项合并处理）。
- 方法总结：先在频域做乘法（代数运算），只在最后一步做反变换。

## 4.5 相乘性质

- 时域相乘 $\leftrightarrow$ 频域卷积：$$x(t)w(t)\longleftrightarrow \frac{1}{2\pi}\int_{-\infty}^{\infty}X(j\theta)W(j(\omega-\theta))d\theta$$
- 因子 $1/2\pi$ 不可漏；这是 CTFS 相乘性质（因子 $T$）的连续谱版本。
- 与卷积性质对偶：卷积 $\leftrightarrow$ 相乘，相乘 $\leftrightarrow$ 卷积（差 $1/2\pi$）。

### 4.5.1 具有可变中心频率的频率选择性滤波

- 目标：中心频率可调的带通滤波器，但只设计一个固定的低通原型 $H_{LP}(j\omega)$。
- 做法：$x(t)$ 乘 $e^{-j\omega_c t}$ 把目标频段搬到零频附近 → 过固定低通 → 乘 $e^{j\omega_c t}$ 搬回去。
- 等效带通冲激响应为 $h(t)=h_{LP}(t)e^{j\omega_c t}$；改变本振频率 $\omega_c$ 即改变中心频率，滤波器本体不变。
- 优点：超外差接收机的原理——固定中频滤波器 + 可变本振实现选台。
- 应用：收音机选台、频分复用系统的信道选择。
- 易错点：实余弦调制产生正负两个边带（双边带）；严格单边搬移需用复指数。

## 4.6 傅里叶变换性质和基本傅里叶变换对列表

性质表：

| 性质 | $x(t)$ | $X(j\omega)$ |
|---|---|---|
| 线性 | $ax+by$ | $aX+bY$ |
| 时移 | $x(t-t_0)$ | $e^{-j\omega t_0}X$ |
| 频移 | $e^{j\omega_0 t}x(t)$ | $X(j(\omega-\omega_0))$ |
| 共轭 | $x^*(t)$ | $X^*(-j\omega)$ |
| 反转 | $x(-t)$ | $X(-j\omega)$ |
| 尺度 | $x(at)$ | $\frac{1}{\lvert a\rvert}X(j\omega/a)$ |
| 时域卷积 | $x*y$ | $XY$ |
| 时域相乘 | $xw$ | $\frac{1}{2\pi}X*W$（频域卷积） |
| 时域微分 | $x'$ | $j\omega X$ |
| 时域积分 | $\int_{-\infty}^{t}x$ | $\frac{1}{j\omega}X+\pi X(0)\delta(\omega)$ |
| 频域微分 | $-jtx(t)$ | $dX/d\omega$ |
| 对偶 | $X(jt)$ | $2\pi x(-j\omega)$ |
| 帕斯瓦尔 | $\int\lvert x\rvert^2dt$ | $=\frac{1}{2\pi}\int\lvert X\rvert^2d\omega$ |
| 实信号 | $x=x^*$ | $X(j\omega)=X^*(-j\omega)$ |

基本变换对：

| $x(t)$ | $X(j\omega)$ |
|---|---|
| $\delta(t)$ | $1$ |
| $1$ | $2\pi\delta(\omega)$ |
| $u(t)$ | $\frac{1}{j\omega}+\pi\delta(\omega)$ |
| $e^{-at}u(t)\ (a>0)$ | $\frac{1}{a+j\omega}$ |
| $te^{-at}u(t)\ (a>0)$ | $\frac{1}{(a+j\omega)^2}$ |
| $e^{-a\lvert t\rvert}\ (a>0)$ | $\frac{2a}{a^2+\omega^2}$ |
| $e^{j\omega_0 t}$ | $2\pi\delta(\omega-\omega_0)$ |
| $\cos(\omega_0 t)$ | $\pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$ |
| $\sin(\omega_0 t)$ | $\frac{\pi}{j}[\delta(\omega-\omega_0)-\delta(\omega+\omega_0)]$ |
| 矩形脉冲（$\lvert t\rvert<T_1$） | $\frac{2\sin(\omega T_1)}{\omega}$ |
| $\frac{\sin(Wt)}{\pi t}$ | 矩形（$\lvert\omega\rvert<W$ 时为 1） |

- 查表方法：先化到表中形式（分解、配方、欧拉展开），再用性质（时移/频移/微分/对偶）拼装。
- $te^{-at}u(t)$ 的变换由频域微分性质得到：$(-jt)e^{-at}u(t)\leftrightarrow \frac{d}{d\omega}\frac{1}{a+j\omega}$。
- $u(t)$ 的对偶形式也可用对偶性由 $\frac{1}{j\omega}+\pi\delta(\omega)$ 推出，注意 $2\pi$ 因子。

## 4.7 由线性常系数微分方程表征的系统

- 系统：$\sum_{k=0}^{N}a_k \frac{d^k y(t)}{dt^k}=\sum_{k=0}^{M}b_k \frac{d^k x(t)}{dt^k}$。
- 对两边取傅里叶变换，用微分性质得 $Y(j\omega)\sum_{k=0}^{N}a_k(j\omega)^k=X(j\omega)\sum_{k=0}^{M}b_k(j\omega)^k$。
- 频率响应（系统函数）：$$H(j\omega)=\frac{Y(j\omega)}{X(j\omega)}=\frac{\sum_{k=0}^{M}b_k(j\omega)^k}{\sum_{k=0}^{N}a_k(j\omega)^k}$$
- 这是 $j\omega$ 的有理函数：分子零点、分母极点决定频率响应形状。
- 例：RC 低通 $\frac{dy}{dt}+\frac{1}{RC}y=\frac{1}{RC}x \implies H(j\omega)=\frac{1}{1+j\omega RC}$，与 3.10.1 用特征函数法结果一致。
- 分析方法：微分方程 $\to$ 频率响应有理式 $\to$ 幅频/相频特性 $\to$ 判断滤波类型（低通/高通/带通）。
- 稳定性要求分母多项式的根（极点）全部位于左半平面，否则 $H(j\omega)$ 不存在（时域发散）。
- 与 3.2 呼应：这里的 $H(j\omega)$ 既是特征值，又是 $h(t)$ 的变换，三种身份统一。

## 4.8 小结

- 非周期信号的傅里叶变换是周期 $T\to\infty$ 的极限：离散谱线 $\to$ 连续谱，离散求和 $\to$ 积分。
- LTI 系统的时域卷积对应频域相乘 $Y=XH$；时域相乘对应频域卷积（带 $1/2\pi$）——对偶的一对定理。
- 周期信号纳入变换框架后频谱为冲激串，CTFS 成为 CTFT 的特例。
- 微分方程描述的系统，其频率响应是 $j\omega$ 的有理函数，可直接读出滤波特性。
- 本章的连续谱思想将在第 5 章平行地用于离散时间信号（DTFT），注意 $2\pi$ 周期性这一新特征。
