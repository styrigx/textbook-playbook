把难啃的专业教材 PDF，整理成条目式、好检索的中文知识库。每条一句话一个知识点，公式用 LaTeX（GitHub 直接渲染）。

## 怎么用

- 按书的章节找：进对应目录的 README，有完整章节索引
- 背公式：每本书都有 `cheatsheet.md` 全书公式速查
- 每章文件结构统一：导读 → 按原书小节组织的知识点条目（概念 / 定义定理 / 公式 / 解题套路 / 易错点）

## 说明

- 这是学习笔记（知识提炼），不是教材原文转载
- 公式已人工核对，仍建议对照原书使用
- 新增教材按同样格式加进来：`新书目录/README.md` + 每章一个文件
